# Off-chain emissions accounting with per-epoch merkle claims

Creator emissions are pro-rata NAV × eligible-time over a permissionless, unbounded Pack set — fully on-chain accrual would need per-Pack per-hour accumulator updates driven by oracle reads, the largest audit surface in the system. Instead, contracts emit ground-truth events (listings, checkpoints, NAV snapshots, selections); the Convex backend computes each epoch's split with a published, reproducible algorithm and posts a merkle claim root; creators and rippers claim against it. Participation rewards use the same pattern. The token contract hard-caps each 150M season allocation regardless of posted roots, so a wrong root can misallocate within a season budget but can never inflate supply. This keeps the House in the same trust class it already occupies for selection (ADR-0001): anyone can recompute and challenge, nobody must trust silently.
