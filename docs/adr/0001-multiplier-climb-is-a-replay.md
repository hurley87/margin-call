# The multiplier climb is a replay of an attested result, not a live event

The crash point is committed as encrypted Inco state before entry opens and revealed only after lock, so the signature crash-game climb cannot happen live during the entry window. We render the climb as a short deterministic replay after finalization — explicitly labelled as a rendering of the attested onchain result, with automatic tier-close pops standing in for manual cashout bubbles — because a climb synchronized to the reveal would inherit Inco's unguaranteed attestation latency and stall dishonestly on delayed rounds, while dropping the climb entirely would discard the genre's signature tension. The replay is a pure function of the finalized crash point: it can be joined mid-playback, replaced by a static card under reduced motion, and never gates or changes settlement.
